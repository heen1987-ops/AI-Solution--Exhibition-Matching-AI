# QAS-005 Handoff

## 완료 내용

`infra/scripts/scope-violation-check`에 키오스크 개인정보 입력필드 정적 검사를 추가했다.

## 검사 범위

- `apps/kiosk/src` 하위 `.ts/.tsx/.js/.jsx` 소스만 검사한다.
- 테스트/fixture 경로(`__tests__`, `*.test.*`, `*.spec.*`)는 제외한다.
- JSX/HTML의 `<input>`, `<textarea>`, `<select>` 태그 속성만 검사한다.
- 업체명 등 읽기 전용 표시 텍스트는 검사 대상이 아니므로 `exhibitor.name` 같은 표시 코드는 통과한다.

## 탐지 조건

- `input type="email"`, `type="tel"`, `type="password"` 발견 시 실패.
- `autocomplete`가 이름/이메일/전화/주소/카드/비밀번호 계열이면 실패.
- 입력 요소의 `name`, `id`, `placeholder`, `aria-label`, `autocomplete` 값에
  `name`, `phone`, `mobile`, `email`, `address`, `company_contact` 또는 한국어 개인정보
  키워드가 포함되면 실패.

## 검증

- `python3 -m py_compile infra/scripts/scope-violation-check` 통과.
- `infra/scripts/scope-violation-check` 통과.
- 스크립트 함수 직접 호출 self-test 통과:
  - 가짜 `<input type="email" name="email">` 위반 탐지.
  - 읽기 전용 `exhibitor.name` + 검색창 통과.
  - 테스트 fixture 경로의 반증 입력은 제외.
- `cd apps/kiosk && npm test -- --run` 통과: 3 files, 29 tests.

## 알려진 제한

- 정적 검사는 JSX 문자열/속성 기반이다. 런타임에서 동적으로 생성되는 입력 속성은
  기존 `apps/kiosk/src/__tests__/no-personal-data-input.test.tsx` 렌더링 테스트가 보완한다.
