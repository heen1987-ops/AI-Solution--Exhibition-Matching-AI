# ADM-001

## 완료 내용

`apps/admin/`에 Next.js 16 / React 19 / TypeScript / Tailwind CSS 4 기반의 관리자 포털 라우트 뼈대를 신규 생성했다. npm workspaces 멤버로 `@backju/admin`(root `package.json`의 `workspaces: ["apps/*", "packages/*"]`가 이미 이를 인식)으로 등록된다. 이번 Wave는 스켈레톤 전용이며 실제 인증/RBAC/승인 워크플로우/감사로그는 의도적으로 구현하지 않았다.

라우트:
- `/` - 관리자 준비 화면(placeholder). 실제 인증·API 호출이 없음을 화면에 명시.
- `/health` - 관리자 앱 상태. `NEXT_PUBLIC_*` 빌드 시점 환경변수(앱 이름/환경/API Base URL/계약 버전)와 이번 Wave 구현 범위 점검표를 정적으로 표시 - 실제 네트워크 요청 없음.
- `/console` - `.harness/worker-prompts.md` 섹션 F(ADMIN 워커 프롬프트) "주요 기능" 14개 영역(행사 설정/사전등록 Import/업체 목록/업체·제품 검수/AI 추출 검수/부스·지도 관리/관심영역 코드/키오스크 설정/바이어 검증/간단 상담 운영/검색 통계/무결과 검색어/사용자·권한/감사로그)을 나열하는 단일 nav-listing 화면. 각 항목은 `role="group" aria-disabled="true"`로 표시되는 비활성 카드이며 실제 링크/버튼이 아니다(클릭 동작 없음) - 실 인증·RBAC이 없는 상태에서 14개 빈 라우트를 만드는 것은 저가치 busywork라고 판단해 데이터 카탈로그(`lib/admin-areas.ts`) + 단일 화면으로 축약했다.

기타:
- `apps/admin/.env.example` - `NEXT_PUBLIC_ADMIN_APP_NAME`/`NEXT_PUBLIC_ENVIRONMENT`/`NEXT_PUBLIC_API_BASE_URL`/`NEXT_PUBLIC_CONTRACT_VERSION`, 각 변수에 "이번 Wave엔 실제로 호출되지 않는다"는 주석 포함.
- Vitest + React Testing Library 컴포넌트 테스트(`apps/admin/__tests__/*`) - Next.js 16 공식 vitest 가이드(`node_modules/next/dist/docs/01-app/02-guides/testing/vitest.md`) 구성을 따름.

## 알려진 제한

- 실제 인증/RBAC/세션 없음(의도된 스코프 - ADM-GROUP-001에서 구현).
- `/console`의 14개 영역은 데이터 카탈로그일 뿐 실제 서브 라우트가 아니다 - 클릭 시 이동하지 않는다(의도됨, 태스크 지시사항).
- `/health`가 표시하는 `NEXT_PUBLIC_API_BASE_URL`/`NEXT_PUBLIC_CONTRACT_VERSION`은 어떤 백엔드에도 연결되지 않는다 - `.harness/contracts/openapi.yaml`이 아직 `0.0.0-draft` 상태(CTR-002 미완료)이므로 의도적으로 정적 표시만 한다.
- Next.js 16.2.12는 학습 데이터 시점 이후 버전(`apps/user-web/AGENTS.md`의 경고 참고) - 이번 작업 전 `node_modules/next/dist/docs/01-app/`(설치 후 로컬 생성)을 직접 읽고 App Router 기본 규칙(`layout`/`page`, `params`/`searchParams`가 Promise, PageProps/LayoutProps 헬퍼)과 vitest 가이드를 확인한 뒤 작성했다 - 큰 breaking change는 이번 스코프(정적 페이지, 동적 라우트 없음)에 해당하지 않았다.
- 루트 `npm install`을 실행해 `package-lock.json`을 갱신했다 - 동시에 다른 트랙(kiosk 등)도 각자 스캐폴딩 중이라 워크스페이스 트리에 `@backju/kiosk` 등이 함께 보이는 것을 확인했지만, 그 경로는 건드리지 않았다.

## 다른 트랙이 해야 할 일

- **BACKEND(BAC-001)**: `/api/v1/system/info` 노출 시 `apps/admin/.env.example`의 `NEXT_PUBLIC_CONTRACT_VERSION` 갱신 참고용으로 실제 `contract_version` 값을 공유해줄 것.
- **CONTRACTS(CTR-002)**: OpenAPI 확정 시 `/console`의 14개 영역 중 이미 존재하는 스키마(바이어 검증=`BuyerNeed.business_email_verified`/`company_verified`, 상담=`Meeting`/`MeetingStatusHistory`/`MeetingContactShare`)에 대응하는 엔드포인트를 `lib/admin-areas.ts`의 `docRef`와 매칭해 Wave 2(ADM-GROUP-001) 착수 시 재사용 가능.
- **ADM-GROUP-001(Wave 2, 본인 트랙 후속)**: 이 스켈레톤 위에 실제 인증(누가 결정할지는 W-9 §1 권한표 참고: `EVENT_ADMIN`/`EXHIBITOR_ADMIN`), 승인·바이어 검증·기본 통계(W-9 §3~§5) 구현. `/console`의 14개 카드 중 우선순위가 높은 것(§3 업체·제품 검수, §4 바이어 검증, §5 기본 통계)부터 실제 서브 라우트로 전환 권장.

## 되돌리는 방법

`apps/admin/` 전체가 신규 디렉터리이므로 `git rm -r apps/admin/`(또는 아직 커밋 전이면 단순 디렉터리 삭제)로 완전히 되돌릴 수 있다. 부수효과인 루트 `package-lock.json` 변경은 `git checkout -- package-lock.json` 후 `npm install`로 재생성하면 된다(다른 트랙이 추가한 의존성까지 함께 사라질 수 있으니, 되돌리기 전 다른 트랙의 workspace 의존성 유무를 먼저 확인할 것).
