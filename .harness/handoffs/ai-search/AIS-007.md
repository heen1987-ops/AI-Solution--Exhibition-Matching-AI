# AIS-007 Handoff - WEB_ONLY 검색 평가셋·RRF Combiner·구조화 Provider

상태: DONE

## 변경 요약

- 기존 kiosk-ko Gold Set 샘플을 WEB_ONLY 범위에 맞춰 `ai/evaluation/queries/guest-web-ko.jsonl`로 전환했다.
- query schema channel enum을 `REGISTERED_WEB`, `GUEST_WEB`, `BUYER_WEB`로 정렬했다.
- `SearchQuery.channel`을 추가하고, 기존 `reciprocal_rank_fusion`을 재사용하는 `ReciprocalRankFusionCombiner`를 구현했다.
- 기존 `structured_search_products`/`structured_search_exhibitors`를 감싸는 `StructuredSearchProvider`를 추가했다.
- `GUEST_WEB_SEARCH_SCORE_V1` 정책을 `src/meet_ai/scoring`에 정의하고 export했다.
