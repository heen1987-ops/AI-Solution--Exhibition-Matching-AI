# AIS-008 Handoff - 게스트 웹 무결과·저신뢰 검색 회복 정책

상태: DONE

## 변경 요약

- `backend/app/services/matching/search_recovery.py`에 순수 정책 함수 `decide_search_recovery`를 추가했다.
- 결과 0건, 저신뢰, 엄격 concept 조건, 온톨로지 gap, 카테고리 0건을 구분한다.
- 회복 action은 `NONE`, `CLARIFY`, `BROADEN_CONCEPTS`, `POPULAR_FALLBACK`, `CATEGORY_FALLBACK` 중 하나다.
- clarification 문구는 이름, 전화번호, 이메일 등 PII 입력을 요구하지 않는다.
- BAC-008에서 `matching.search_query.fallback_reason`과 `SearchResponse.meta`에 연결할 수 있도록 DB 의존 없는 함수로 유지했다.
