# CTR-006/CTR-007 Handoff

## 완료 내용

- `profile.saved_recommendable` 모델과 Alembic 마이그레이션을 추가했다.
- `ai.source_document`, `ai.extracted_attribute`, `ai.content_approval`, `ai.ai_execution_log`, `ai.embedding_document`, `ai.embedding_vector` 모델과 Alembic 마이그레이션을 추가했다.

## DB 변경

- `0011_saved_recommendable`: 관심 저장 테이블, 중복 저장 방지 unique, 조회 인덱스.
- `0012_ai_schema`: AI 구조화·승인·로그·임베딩 테이블, `CREATE EXTENSION IF NOT EXISTS vector`.
- 임베딩 컬럼은 모델 차원 미확정 상태를 고려해 `vector` 타입 + `embedding_dimension` 컬럼으로 시작한다.

## 알려진 제한

- PostgreSQL 16 Homebrew 인스턴스에는 pgvector extension 파일이 없어 `CREATE EXTENSION vector`가 실패했다. PostgreSQL 17 Homebrew 인스턴스에서는 pgvector가 설치되어 왕복 검증이 성공했다.
- `alembic check`는 기존에 문서화된 `exhibition.profile_attribute`의 `fk_supply_profile_attribute_concept_code` 드리프트를 계속 보고한다. 이번 CTR-006/007 신규 스키마로 인한 드리프트는 아니다.
