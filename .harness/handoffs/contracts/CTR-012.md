# CTR-012 Handoff - Search Persistence Channels and Search Indexes

상태: DONE

## 변경 요약

- `matching.search_session.channel` 모델 값을 `REGISTERED_WEB/GUEST_WEB/BUYER_WEB/ADMIN_PREVIEW`로 정렬했다.
- `channel` 컬럼 길이를 `String(10)`에서 `String(30)`으로 확장했다.
- migration `0013_search_web_only_indexes`를 추가했다.
- legacy `WEB` 값은 `REGISTERED_WEB`, legacy `KIOSK` 값은 `GUEST_WEB`로 backfill한다.
- FTS expression GIN index와 pgvector HNSW cosine ANN index를 추가했다.
