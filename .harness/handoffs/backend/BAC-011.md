## 동작 계약

- 공개 업체 조회는 `exhibitor.master_approval_status = APPROVED`이고 `deleted_at IS NULL`인 업체만 반환한다.
- 공개 부스 조회는 승인 업체 + 승인 참가(`participation_status=APPROVED`)에 연결된 부스만 반환한다.
- 미승인 업체/부스는 존재 여부를 숨기기 위해 404를 반환한다.
- 부스 상태 변경은 OPERATOR/ADMIN + `X-MeetAI-User-Id`를 요구한다.
- `row_version`이 요청에 있으면 낙관적 동시성 검사 실패 시 `RESOURCE_CONFLICT`를 반환한다.
- 상태 변경은 `exhibition.booth_status_history`에 append-only 이력을 남긴다.
