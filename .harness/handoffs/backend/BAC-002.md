# BAC-002 Handoff

Date: 2026-08-02
Track: BACKEND
Status: DONE

## Completed

Added a v1 API request-context dependency for protected endpoints. The context
uses explicit local/test headers only and does not collect or infer PII.

Headers:

- `X-MeetAI-Profile-Id`: `profile.user_profile.profile_id`
- `X-MeetAI-User-Type`: `GENERAL_REGISTERED`, `BUYER_REGISTERED`, or `GUEST_WEB`
- `X-MeetAI-User-Id`: `profile.user_account.user_id` for operator/admin actions
- `X-MeetAI-Actor-Role`: existing actor role code, including `OPERATOR` and `ADMIN`
