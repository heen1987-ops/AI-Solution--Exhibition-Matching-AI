# Handoffs

각 트랙 하위 디렉터리(`contracts/`, `backend/`, `user-web/`, `kiosk/`, `admin/`, `ai-search/`, `qa/`)에 태스크 완료 시 `{task-id}.md`를 생성한다. 형식은 메타프롬프트 §16을 따른다:

```text
# Task ID
## 완료 내용
## 변경 파일
## 공개 인터페이스
## DB 변경
## 테스트
## 알려진 제한
## 다른 트랙이 해야 할 일
## 되돌리는 방법
## 다음 권장 작업
```

다른 트랙의 소유 경로 수정이 필요하면 코드를 직접 고치지 말고 그 트랙 디렉터리에 요청 파일을 남긴다.
