# apps/

Next.js 프런트엔드 3종의 위치 (npm workspaces 멤버). 아직 비어 있다 - Wave 1에서 다음 순서로 생성된다:

- `user-web/` - 웹 초개인화 모듈 (`WEB-001`, `docs/redesign-v2/web/W-3-screen-ia.md` S-1~S-8)
- `kiosk/` - 키오스크 이식형 검색모듈 (`KSK-001`, `docs/redesign-v2/kiosk/K-3-screen-ia.md` K-S1~K-S8)
- `admin/` - 관리자 포털 (`ADM-001`, `docs/redesign-v2/web/W-9-admin-operations.md`)

기존 `backend/`(FastAPI)는 이 디렉터리로 이동하지 않는다 - `.harness/assumptions.md` ASSUMPTION-001 참고.
