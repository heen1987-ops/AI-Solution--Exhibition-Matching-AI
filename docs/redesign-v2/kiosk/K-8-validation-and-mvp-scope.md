# K-8. 키오스크 이식형 검색모듈 - 검증·MVP 범위

근거 문서: `docs/redesign-v2/00-master-spec-v1.md`(§45.2, §54, §56), `docs/redesign-v2/01-module-split-plan.md`(§4-B K-8). K-1~K-7을 종합해 키오스크 모듈 설계를 마감한다. 이 문서를 끝으로 재설계 진행순서(§7)의 "2차: 키오스크 이식모듈"이 완료되고, "3차: 공통 AI·데이터 플랫폼(C-1~C-8)"으로 넘어간다.

## 1. 검색 성공률

- [K-4 §4](../kiosk/K-4-natural-language-search-logic.md)의 "결과 0건 → 온톨로지 상위 확장 → 그래도 0건이면 최소 추가질문" 경로가 실제로 검색 실패율을 낮추는지가 검증 대상 - 단, 실제 성공률 수치 목표(예: 95%)는 마스터 스펙에 구체적으로 명시되어 있지 않으므로 이 문서에서 임의로 수치를 정하지 않는다. **정성적 검증**(결과 0건 화면이 최소 추가질문 없이 방치되지 않는지)까지만 MVP 검증 범위로 한다.

## 2. 응답시간

- 현장 키오스크는 대기 줄이 생길 수 있는 환경이므로 체감 응답속도가 중요하나, 구체적 SLA(예: p95 500ms)는 마스터 스펙에 없다 - 이 항목은 실제 부하 테스트가 가능한 구현 단계로 넘기고, 설계 문서 수준에서는 "[K-7 §6](K-7-portable-package-structure.md) 자동 업데이트가 세션 도중에 실행되어 응답을 지연시키지 않는지"만 확인한다.

## 3. 세션 초기화 검증

- [K-2 §6](K-2-user-flow.md)의 3가지 트리거(완료 버튼/QR 스캔/타임아웃) 각각이 실제로 [K-1 §4](K-1-service-scope.md)의 "개인정보 잔존 없음" 상태로 돌아가는지 확인 - 서버 측은 애초에 `UserProfile`을 만들지 않으므로 자동으로 충족되고([K-1 §1](K-1-service-scope.md)), 클라이언트 측(화면에 남은 검색어·결과 텍스트)은 프론트엔드 구현에서 초기화 트리거 시 상태를 완전히 리셋하는지가 검증 포인트.

## 4. 개인정보 잔존 검증

- [K-1](K-1-service-scope.md) 전체가 이미 이 원칙을 스키마 차원에서 보장한다는 것을 확인했다(`GuestSession`은 개인정보 컬럼이 없고, `KIOSK_GUEST`에는 `UserProfile`을 만들지 않음). K-8에서는 이를 다시 계산하지 않고, **회원가입·연락처·장기행동정보 3개 중 어느 것도 키오스크 경로로 수집되지 않는지**를 API 계약 리뷰로 재확인하는 것으로 충분하다(01-module-split-plan.md §5 확정사항 5).

## 5. 현장 사용성

- [K-2 §6](K-2-user-flow.md)/[K-3 §3](K-3-screen-ia.md)에서 미정으로 남긴 정확한 타임아웃 값(무입력 초기화 시간)을 이 문서에서 확정하지 않는다 - 이는 실제 전시장 현장 테스트(파일럿 운영)를 통해 조정해야 하는 값이므로, 설계 문서가 임의의 초 단위를 못박기보다 **"설정 파일([K-7 §1](K-7-portable-package-structure.md))의 조정 가능한 값으로 둔다"**는 것이 이 문서의 결정이다 - 즉 타임아웃 자체를 하드코딩하지 않고 운영 중 튜닝 가능하게 만드는 것이 MVP 요구사항이다.

## 6. 장애대응

- [K-3 §2](K-3-screen-ia.md)의 3가지 오류화면(결과없음/네트워크단절/QR실패)과 [K-7 §7](K-7-portable-package-structure.md)의 로컬 캐시 폴백이 장애대응의 전부다 - 이 이상의 정교한 장애 복구(자동 페일오버, 다중 리전 등)는 §56 "복잡한 MLOps" 제외 원칙에 해당하므로 MVP 범위 밖.

## 7. MVP 제외 최종 확인 (K-1~K-7 전체 재확인)

- 키오스크 회원가입·장기 프로파일·개인정보 입력 (K-1 §1, §6 절대 원칙)
- 복잡한 방문경로 최적화 (K-5 §2, 구역 단위 안내만)
- 음성입력 (K-6 §3, 확장 항목)
- 정교한 무중단 배포·자동 페일오버 (K-7 §6, K-8 §6)
- 세션 도중 언어 전환 (K-3 §3)

## 8. 키오스크 모듈 설계 완료 선언

K-1([서비스 범위](K-1-service-scope.md))부터 K-7([이식형 패키지 구조](K-7-portable-package-structure.md))까지 미결정 항목이 모두 해소되었다(§4의 C-4 이관 사항 1건 제외 - 이는 공통 플랫폼 설계가 선행돼야 답할 수 있는 항목이므로 K 시리즈 자체의 미완료가 아니다). 다음 작업은 `docs/redesign-v2/01-module-split-plan.md` §7의 순서에 따라 **C-1(업체·부스 데이터 모델)**부터 시작한다 - K-4 §5, W-5 §6에서 이미 C-4로 이관해 둔 검색·점수식 통합 질문들이 C 시리즈의 핵심 의제가 된다.
