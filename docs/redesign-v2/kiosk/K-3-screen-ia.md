## 2. 오류화면 - 신규 정의(K-2에 없던 예외 경로)

마스터 스펙 §23의 핵심기능 목록에 "오류화면"이 명시되어 있으므로, 다음 3가지 오류 상태를 별도 화면으로 정의한다(K-2의 정상 흐름에는 없었던 분기).

1. **검색 결과 없음**: 오류가 아니라 정상 응답의 한 형태 - [K-2 §4](K-2-user-flow.md)의 "최소 추가질문" 또는 "인기 카테고리 안내"로 유도. 엄밀히는 K-S8이 아니라 K-S4의 한 상태(empty state)로 처리한다.
2. **네트워크 단절**: 공통 플랫폼 API(C-4/C-5) 응답 없음 - K-7(이식형 패키지 구조)의 로컬 캐시로 폴백하거나, 캐시도 없으면 "일시적으로 검색이 어렵습니다" 안내와 함께 대기화면으로 자동 복귀.
3. **QR 인계 실패**: 모바일 스캔은 됐으나 세션 생성이 실패한 경우 - 재시도 버튼 제공, 반복 실패 시 대기화면 복귀.

## 3. 화면 간 이동 제약

- **뒤로가기의 범위**: K-S4(결과 목록)/K-S5(상세)/K-S6(지도)에서는 이전 화면으로 돌아갈 수 있지만, K-S1(대기화면)으로는 오직 (a) 완료 버튼, (b) 타임아웃, (c) QR 스캔 완료([K-2 §6](K-2-user-flow.md)) 3가지 트리거를 통해서만 도달한다 - 사용자가 "뒤로가기"를 연타해서 이전 세션 상태로 되돌아가는 경로는 만들지 않는다(각 화면은 항상 "앞으로만" 진행하다가 트리거로 리셋되는 단방향 흐름).
- **K-S2(언어 선택)는 세션당 1회만 노출**: 검색 도중 언어를 바꾸고 싶다면 세션을 초기화하고 처음부터 다시 시작해야 한다 - 이는 마스터 스펙에 명시된 요구는 아니지만, "세션 중 언어 전환" 기능이 §56의 어떤 제외 항목에도 명시적으로 해당하지는 않되 MVP 범위를 넓히는 결정이므로 기본값은 미포함으로 하고, 필요 시 K-6(다국어·접근성)에서 재검토한다.

## 4. K-4로 넘기는 질문

1. 검색 결과 없음(§2-1)일 때 "최소 추가질문"의 정확한 트리거 조건(결과 0건일 때만인지, 결과가 너무 많을 때도인지) - K-4(자연어 검색 로직)에서 확정.
