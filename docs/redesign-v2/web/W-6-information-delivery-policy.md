# W-6. 웹 초개인화 모듈 - 정보전달 정책

근거 문서: `docs/redesign-v2/00-master-spec-v1.md`(§8, §23~25 개인정보·동의), `docs/redesign-v2/01-module-split-plan.md`(§4-A W-6). [W-2 §1-9](W-2-user-journey.md), [W-1 §6-4](W-1-scope-and-user-types.md)에서 미결정으로 남긴 "행사 후 알림 채널 범위"를 확정한다.

## 1. 정보전달 3단계 (행사 전/당일/후)

| 단계 | 채널 | 트리거 | 비고 |
| --- | --- | --- | --- |
| 행사 전 | 웹(S-1/S-2 진입 시 표시) | 로그인 | [W-2 §1-4](W-2-user-journey.md) 사전 추천과 동일 데이터 |

## 2. "1회성 정적 알림"과 "마케팅 자동화"의 경계 (미결정 사항 확정)

마스터 스펙 §56은 "독립 마케팅 자동화 플랫폼"을 제외하면서도 §8.2-11에는 "행사정보 알림"을 요구 기능으로 남겨, [W-1 §6-4](W-1-scope-and-user-types.md)에서 경계가 모호하다고 지적했다. 다음 기준으로 확정한다.

- **포함(1회성 정적 알림)**: 행사 종료 후 "관심 저장한 업체 목록 요약", "참여 확인" 등 **행사 1회당 최대 1~2회, 사전 정의된 템플릿**으로 발송되는 정보. 발송 대상은 `profile.saved_recommendable`([W-4 §6](W-4-profile-model.md) 신규 테이블) 존재 여부로 결정되는 정적 조건이다.
- **제외(마케팅 자동화)**: 사용자 행동에 따라 분기하는 드립 캠페인, A/B 테스트, 재참여 유도 시퀀스, 반복 발송 스케줄러. 이런 기능은 "조건에 따라 계속 다른 메시지를 보내는" 동적 캠페인 엔진을 필요로 하며, MVP 범위에 없다.
- **판별 규칙**: "발송 횟수가 행사 1회당 고정된 상한이 있고, 발송 조건이 정적 데이터 조회만으로 결정되면" 포함 대상이고, "발송 여부·내용이 이후 사용자 반응에 따라 달라지면" 제외 대상이다.

## 3. 채널 구현 방식

- 이메일 발송 자체는 웹 모듈이 아니라 공통 플랫폼(C-7 인프라)의 워커(§C-7 "웹·키오스크 API, DB, 캐시... 모니터링")가 담당한다 - 웹 모듈은 "발송 대상·내용을 결정"하는 정책까지만 소유하고, 실제 SMTP/문자 발송은 C-7의 책임으로 넘긴다.
- 문자(SMS) 발송은 이번 MVP 범위에 포함하지 않는다 - 마스터 스펙에 이메일만큼 구체적으로 명시되지 않았고, 별도 발신번호·사업자 등록이 필요한 규제 이슈가 있어 확장 항목으로 분류한다. **이 결정은 사용자 확인 없이 문서에 기본값으로 기록하며, 이견이 있으면 W-8에서 재검토 가능.**

## 4. 수신동의

- 기존 `profile.consent_policy`/`profile.user_consent`(purpose 자유 문자열, 이전 세션에서 확인)를 그대로 재사용한다.
- 웹 모듈이 사용하는 `purpose` 표준값을 다음 3개로 확정한다(자유 문자열이므로 CHECK 제약은 걸지 않되, 서비스 정책으로 고정): `EVENT_INFO_NOTIFICATION`(행사정보 알림 - §2의 포함 대상), `PERSONALIZED_RECOMMENDATION`(개인화 추천 계산 근거로 프로파일 사용), `BUYER_CONTACT_SHARE`(바이어 상담 시 연락처 공유 - [W-2 §2](W-2-user-journey.md)의 `MeetingContactShare`와 연동).
- 동의 철회 시 `EVENT_INFO_NOTIFICATION` 철회는 발송 중단만, `PERSONALIZED_RECOMMENDATION` 철회는 개인화 추천 자체를 중단하고 비개인화(카테고리 인기 순 등) 추천으로 폴백해야 한다 - 폴백 로직의 구체적 알고리즘은 W-5에서 다루지 않았으므로 여기서 보완: 콜드스타트와 동일하게 처리한다(01-module-split-plan.md §6 "콜드스타트 → 키오스크 검색으로 단순화" 원칙을 재사용해, 동의 철회 사용자도 키오스크 검색과 동일한 무프로파일 검색 경로로 전환).

## 5. W-7로 넘기는 질문

1. `BUYER_CONTACT_SHARE` 동의와 기존 `MeetingContactShare`의 `disclosed` 플래그가 정확히 어떻게 연동되는지(동의 철회 시 이미 공유된 연락처를 소급 삭제하는지) - W-7에서 확정.
