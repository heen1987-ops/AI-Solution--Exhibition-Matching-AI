# 12단계. 바이어 B2B 매칭점수 설계

> 문서 상태: 30단계 통합 설계 로드맵 — 12단계 산출물 (이후 13단계부터 웹/키오스크 분리 재설계로 전환됨 — [redesign-web-kiosk-split.md](./redesign-web-kiosk-split.md) 참고)
> 로드맵: [30단계 통합 설계 로드맵](./00-roadmap.md)

## 1. 단계 목적

본 단계의 목적은 바이어의 제품수요, 유통채널, 가격조건, 주문수량, 공급지역, 협력방식과 참가업체의 제품·거래·생산·유통역량을 비교하여 바이어 관점의 B2B 거래 적합도를 0~100점으로 산출하는 데 있다.

본 점수는 다음 용도로 활용한다.

- 바이어별 참가업체 추천순위 산정
- 제품·업체 비교
- 상담 추천대상 선정
- 거래조건 불일치 원인 분석
- 상담 전 확인사항 제시
- 상담 후 유효리드 가능성 평가
- 거래유형별 가중치 적용
- 실제 상담·후속거래 데이터를 활용한 모델 보정

본 단계의 점수는 바이어가 업체를 얼마나 원하는지를 나타낸다. 업체가 해당 바이어를 얼마나 원하는지는 제13단계 양면 적합도 모델에서 별도로 계산한다(단, 13단계는 재설계로 인해 웹 모듈의 "양면 적합도" 항목으로 축소 반영됨 — §35.3 참고).

## 2. 핵심 설계 판단

### 2.1 B2C 점수모델과 분리

일반 관람객 추천은 맛·향·가격·시음 경험이 중요하지만, 바이어 매칭은 다음 조건이 우선한다.

- 제품군
- 유통채널
- 공급가격
- MOQ
- 생산여력
- 공급지역
- 납기
- OEM·PB·수출 가능성
- 상담 준비도
- 거래정보의 검증수준

제품이 매력적이어도 주문수량, 납기, 공급지역을 충족하지 못하면 거래 추천으로는 부적합하다.

### 2.2 거래 가능성과 거래 매력도 분리

B2B 매칭점수는 다음 두 계층으로 구분한다.

- ① 거래 가능성 Feasibility: 거래조건을 실제로 충족할 수 있는가
- ② 거래 매력도 Attractiveness: 바이어의 전략·제품·채널 목적에 얼마나 적합한가

필수조건을 충족하지 못한 후보는 제10단계에서 제거한다. 본 단계는 필수조건을 통과한 후보 간 상대적 적합도를 계산한다.

### 2.3 업체 인기보다 거래조건 우선

다음 정보는 B2B 기본 적합도에 직접 포함하지 않는다.

- 일반 관람객 방문자 수
- 소비자 인기순위
- SNS 팔로워 수
- 행사 부스 규모
- 스폰서 여부
- 단순 브랜드 인지도

바이어가 대형 브랜드를 원한다는 조건을 명시한 경우에는 별도 사업규모 속성으로 반영할 수 있으나, 일반 인기점수로 대체하지 않는다.

### 2.4 미확인 거래정보는 중립이 아님

MOQ UNKNOWN, 생산량 UNKNOWN, 공급지역 UNKNOWN과 같은 상태를 조건 충족으로 간주하지 않는다.

- 필수조건: 제10단계에서 제외 또는 수동확인
- 선호조건: 감점
- 협의 가능조건: 조건부 점수 부여
- 상담추천: 확인 필요사항으로 표시

## 6. 미입력 항목 처리

바이어가 특정 조건을 입력하지 않은 경우 해당 항목을 0점 처리하지 않는다.

```text
입력 없음 → 해당 항목 계산 제외 → 나머지 가중치 재정규화
```

다만 다음 핵심 항목이 누락되면 정밀 B2B 추천이 아니라 탐색형 추천으로 분류한다: 거래목적, 제품군, 유통채널, 주문규모 또는 MOQ, 공급지역.

## 10. 가격·수익구조 적합도

### 10.1 가격 기준 일치

소비자가, 도매가, 공급가, 행사 판매가, OEM 예상가, 샘플가 — 바이어가 요구한 기준과 업체 가격의 기준이 일치해야 한다.

### 10.2 목표 가격범위 적합도

```text
업체 가격이 목표범위 안 → P_price = 1.00
목표 최대가격 초과 시:
P_price = max(0, 1 - (업체가격 - 목표최대가격) / 목표최대가격)
```

목표 최소가격보다 낮은 경우에는 가격이 낮다는 이유만으로 강하게 감점하지 않는다. 다만 프리미엄 포지셔닝과 충돌할 경우 제품전략 점수에서 감점한다.

### 10.3 예상 마진 적합도

```text
예상 마진율 = (예상 판매가 - 공급가) / 예상 판매가
예: (50,000 - 30,000) / 50,000 = 0.40
```

### 10.4 목표 마진 점수

```text
실제 마진율 >= 목표 마진율 → 1.00
실제 마진율 < 목표 마진율 → 실제 마진율 / 목표 마진율
```

### 10.5 가격·마진 결합

```text
P = 0.60 × PriceRangeMatch + 0.40 × MarginMatch
```

마진정보가 없으면 가격범위 점수를 100% 적용한다.

## 11. MOQ·주문규모 적합도

### 11.1 비교값

업체 최소주문수량, 바이어 초기 주문 가능량, 바이어 정기 주문량, 포장단위, 샘플 주문 가능성, MOQ 협의 가능 여부

### 11.2 완전 적합

```text
업체 MOQ <= 바이어 희망 주문량 → 1.00
```

### 11.3 조건부 적합

```text
Q = max(0.40, 바이어 주문량 / 업체 MOQ)
예: 바이어 200병, 업체 MOQ 300병, 협의 가능 → Q = max(0.40, 200/300) = 0.667
```

### 11.4 여유 적합도

MOQ가 낮다고 무조건 더 높은 점수를 주지는 않는다. `MOQ <= 바이어 주문량 → 기본 1.00`.

### 11.5 포장단위 보정

바이어 희망 100병, 업체 포장단위 12병 → 실제 가능 주문 108병. 포장단위를 반영한 실제 주문 가능량으로 비교한다.

### 11.6 정보 미확인

MOQ 미등록: 0.20~0.40, 협의 가능 표기: 0.50~0.70, 검증된 MOQ: 최대 1.00

## 12. 생산여력·납기 적합도

### 12.1 생산여력 비교

```text
Capacity Ratio = 업체 신규공급 가능량 / 바이어 예상 주문량
```

### 12.2 생산여력 점수

| Capacity Ratio | 점수 |
|---|---|
| 1.5 이상 | 1.00 |
| 1.0~1.49 | 0.90 |
| 0.8~0.99 | 0.60 |
| 0.5~0.79 | 0.30 |
| 0.5 미만 | 제10단계 제외 또는 0 |
| 미확인 | 0.25 |

잔여 생산량 부족이 확정된 경우 필수조건 필터에서 제외한다.

### 12.3 납기 적합도

```text
납기 이내 공급 → LeadTimeMatch = 1.00
납기 초과: LeadTimeMatch = max(0, 1 - (업체납기 - 바이어허용납기) / 바이어허용납기)
```

### 12.4 생산·납기 결합

```text
K = 0.60 × CapacityMatch + 0.40 × LeadTimeMatch
```

정기납품 목적에서는 생산여력 비중을 높일 수 있다.

| 가능·업체 확인 | 0.90 |
| 조건부 가능 | 0.65 |
| 협의 가능 | 0.55 |
| 미확인 | 0.20 |
| 불가능 | 필수 시 제외, 선호 시 0 |

### 14.3 복수 협력방식

```text
X = Σ 협력방식별 적합도 × 중요도
예: OEM 필수 0.70, 공동마케팅 선호 0.30
```

필수 OEM 불가 업체는 제10단계에서 제거되므로 본 점수에는 남지 않는다.

## 15. 상담 실행가능성


### 15.3 상담 미지원 처리

거래 적합도는 높지만 현장상담이 불가능한 경우: 기본 거래 적합도 유지, 상담 실행가능성 낮음, 추천 행동은 `SAVE_FOR_FOLLOW_UP`. 업체 자체를 부적합 처리하지 않고 추천 행동을 조정한다.

## 16. 거래 준비도·데이터 신뢰도

### 16.1 거래 준비도

제8단계에서 산출한 요소 사용: 가격·MOQ 명확성, 생산·납기 정보, 공급지역, 담당자, 인증·증빙, 신규 거래 가능 여부

### 16.2 데이터 신뢰도

```text
Data Trust = 0.35×Verification + 0.25×Completeness + 0.20×Freshness + 0.20×Consistency
```

### 16.3 결합식

```text

```

거래 준비도는 업체의 품질이나 우수성을 뜻하지 않는다. 상담을 진행할 만큼 조건이 정리되어 있는지를 의미한다.

## 20. 점수 보정 규칙

### 20.1 필수조건 근접 실패 보정 금지

필수조건을 통과하지 못한 업체를 점수로 복구하지 않는다. (필수 MOQ 불일치 → 제외, 높은 제품 적합도 → 복구 불가)

### 20.2 협의 가능 조건

NEGOTIABLE은 완전 일치보다 낮고 불가능보다 높게 처리한다. 권장 초기값: 협의 가능 0.55, 조건부 가능 0.65, 확정 가능 0.90~1.00

### 20.3 검증자료 보정

업체가 제출한 거래조건이 검증된 경우 신뢰도와 준비도에 가점을 부여한다. 다만 적합도 자체를 부풀리지 않는다.

## 22. 추천 이유 선정

- 지양 이유: 유명 업체, 인기 부스, 방문자가 많음, 업계 최고, AI가 높은 점수를 부여함
