# backju.kr 관리자 사이트 이식 계약

## 확인된 현재 상태

2026-08-01 기준 `https://www.backju.kr/adm/` 직접 접근은 JavaScript 경고창 뒤
`오류안내 페이지`를 표시한다. 따라서 `/adm/` 내부 경로, PHP 세션, 관리자 DB 스키마를
안정적인 연동 계약으로 가정하지 않는다.

## 이식 원칙

1. 매칭 플랫폼은 기존 사이트와 분리된 모듈형 모놀리스로 배포한다.
2. 기존 PHP 페이지는 버전형 HTTP API, 웹훅 또는 프레임워크 비종속 위젯만 호출한다.
3. 기존 사이트 DB를 직접 조회하거나 `/adm/` 세션 쿠키를 공유하지 않는다.
4. 모든 호출은 `tenant_id`, `event_id`, `request_id`, `idempotency_key`를 가진다.
5. 브라우저 위젯에는 장기 비밀키를 넣지 않는다. 서버가 발급한 짧은 수명의 행사 범위
   토큰만 사용한다.
6. 추천 점수, 정책 버전, 필터 평가 ID와 계산 지문은 외부 화면 형태와 무관하게 동일하다.
7. API 연동이 불가능한 운영 환경에는 같은 정규화 계약을 사용하는 CSV 가져오기/내보내기를
   제공한다.

## 권장 연결 구조

```text
backju.kr 사전등록/PHP 관리자
        │
        ├─ 서버 웹훅 ── 참가자·업체 변경 이벤트
        ├─ REST API ─── 추천 조회·상담 요청·피드백
        └─ JS 위젯 ──── 추천 카드·상담 UI
                         │
                         ▼
              독립 AI 매칭 플랫폼
              ├─ 정규화/동의 계층
              ├─ 하드필터
              ├─ 결정론적 점수 코어
              ├─ 상황 재정렬
              └─ 결과·근거 저장소
```

## 배포 형태

| 형태 | 기존 사이트 변경 | 적용 상황 |
|---|---:|---|
| 외부 모듈형 서비스 | API·스크립트 태그 추가 | 기본 권장안 |
| 동일 도메인 리버스 프록시 | `/matching/*` 라우팅 추가 | 쿠키 없는 동일 출처 UI 필요 시 |
| 운영자 전용 별도 콘솔 | 관리자 메뉴에 링크 추가 | `/adm/` 수정 권한이 제한될 때 |
| CSV 교환 | 업로드·다운로드 메뉴 추가 | API 개발이 당장 불가능할 때 |

## 공개 경계

- 공개 API: `/api/v1/recommendations`, `/api/v1/meetings`, `/api/v1/feedback`
- 파트너 수집 API: `/partner/v1/events/{event_id}/registrations`,
  `/partner/v1/events/{event_id}/exhibitors`
- 웹훅: 프로파일·업체·재고·상담 상태 변경 알림
- 위젯: `data-event-id`와 단기 세션 토큰으로 초기화

API 응답은 ORM 객체나 내부 테이블 ID 전체를 노출하지 않는다. 기존 사이트가 보관하는 이름,
휴대전화, 이메일은 동의 목적에 필요한 범위에서만 전송하며 추천 프로파일과 분리한다.

## 현재 구현과의 연결

`src/meet_ai/scoring`은 FastAPI, PHP, Netlify 또는 특정 DB에 의존하지 않는 순수 Python
패키지다. 백엔드는 `app.services.matching.base_scoring`과
`app.services.matching.reciprocal_matching` 어댑터를 통해서만 이 코어를 호출한다. 따라서
향후 backju.kr 연동 방식이 API, 위젯 또는 CSV로 바뀌어도 점수 정책과 계산 결과는 바뀌지
않는다.

14단계 상황 재정렬도 같은 이식 원칙을 따른다. 기존 사이트는 현재 구역·잔여시간을 서명형
사이트 컨텍스트로 전달하고, 혼잡·대기·재고·상담 슬롯은 제공 가능한 모듈만 연결한다. 누락된
모듈은 0점으로 간주하지 않고 해당 신호의 가중치를 제외하므로 `/adm/` 확장 권한이 제한되거나
일부 운영 테이블을 제공하지 않는 설치 환경에서도 기본 적합도를 훼손하지 않는다. 자세한
계산·저장 계약은 [14단계 상황인지 재정렬](./14-context-aware-reranking.md)을 따른다.

실제 관리자 연동은 `/adm/`의 비공개 내부 구조를 추측해 구현하지 않는다. 운영사로부터 다음
중 하나를 확인받은 뒤 연결한다.

- 공식 관리자 API 또는 웹훅 등록 지점
- PHP 소스에서 확장 가능한 메뉴·컨트롤러 위치
- 허용된 CSV 가져오기/내보내기 형식
- 행사·참가자·업체의 외부 식별자 매핑 규칙
